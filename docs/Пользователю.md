# Как пользоваться программой «Конвектор загрузки»

## 1. Что делает программа

Берёт счета, накладные, приложения к ТТН, прайс-листы поставщиков (файлы `.xls`, `.xlsx`,
`.csv`, `.txt`, `.html`) и делает из них **одну таблицу Excel по установленному образцу**:

| Штрихкод | Артикул | Наименование товара | ед. изм. | количество | цена | сумма | ставка НДС | сумма НДС | сумма с НДС |
|---|---|---|---|---|---|---|---|---|---|

Одновременно программа **проверяет арифметику**: перемножает количество на цену,
считает НДС по ставке, складывает сумму с НДС и сверяет с итогами документа.
Если что-то не сходится — это видно на отдельном листе.

## 2. Запуск

* `Konvektor.exe` — оконная версия. Ничего устанавливать не нужно: скопируйте файл
  в любую папку и запустите двойным щелчком.
* `Konvektor-cli.exe` — та же программа без окна, для пакетной обработки (см. раздел 8).
* Если Windows покажет предупреждение «Не удалось проверить издателя», нажмите
  «Подробнее» → «Выполнить в любом случае» (файл собран автоматически на GitHub,
  без сертификата подписи кода).

## 3. Порядок работы

Программа обрабатывает **один файл за раз** — так проще проверить результат
и не перепутать документы.

1. **«Выбрать файл…»** — указать счёт/накладную/прайс (`.xls`, `.xlsx`, `.csv`,
   `.html`, `.txt`). Файл можно и просто перетащить мышью на ярлык `Konvektor.exe`.
   Сразу после выбора программа спросит **склад** — «Мир» или «Кореличи» — и
   предложит выбрать **одного или нескольких поставщиков этого склада** из
   загруженной ведомости. Если ведомость ещё не загружена, поставщика программа
   возьмёт из счёта; после её загрузки нужно выбрать поставщиков через «Изменить…».
   Передумали — нажмите **«Изменить…»**
   в строке «Склад и поставщик».
2. Поле **«Куда сохранить»** — обычное поле пути, как в любой программе Windows.
   В нём уже стоит папка **«Документы»**: можно оставить как есть, стереть
   (тогда результат снова пойдёт в «Документы») или вписать любой другой путь,
   например `D:\Отчёты\Конвектор` — папку создаст сама программа. Кнопка
   **«Обзор…»** справа от поля открывает обычный выбор папки и подставляет
   выбранный путь в это же поле.
   Когда склад выбран, результат раскладывается по папкам:
   **`<папка из поля>/<склад>/<поставщик>/<дата>.xlsx`** — например
   `D:\Отчёты\Конвектор\Мир\ООО ОМА\15.11.2026.xlsx`. Если склад не выбран,
   имя прежнее — **`поставщик дата.xlsx`** прямо в папке из поля. Несколько
   поставщиков перечисляются в имени папки по алфавиту через запятую.
   Дата — **сегодняшняя, дата сохранения**, а дата самого документа остаётся
   на листах «Сводка» и «Проверки». Поэтому «Результат.xlsx» не появится.
   Если файл с таким именем уже есть, новый сохранится как
   `15.11.2026 (2).xlsx` — **предыдущий результат не затирается**.
3. Нажать одну из трёх кнопок: **«Конвертировать по штрихкоду»**,
   **«Конвертировать по артикулу»** или **«Конвертировать по наименованию»**.
   Файл на этом шаге **не записывается** — программа только разбирает документ.
   Кнопки отличаются только способом сверки с ведомостью (см. раздел 4);
   если ведомость не загружена, все три делают обычную конвертацию.
4. Внизу окна вместо журнала сразу показывается **готовая таблица** — те же
   **10 колонок** и значения, что попадут в лист «Данные», с разлиновкой
   (строки подсвечены через одну, вокруг таблицы рамка). В окне при
   загруженной ведомости добавляются «Из документа», «Из ведомости», «▼» и
   «% совпадения»; **в файле** после «сумма с НДС» появляется только колонка
   «Новинка» (см. раздел 4). В колонках «количество» и «ставка НДС» лишней
   запятой нет.
5. По окончании появляется сообщение: количество позиций, поставщик и документ,
   расхождения и сколько значений посчитано. **Список файлов очищается сам** —
   можно сразу выбирать следующий.
6. Проверить таблицу и нажать **«Сохранить»** (кнопка становится доступной
   после разбора). Куда именно будет записан файл, написано в подсказке
   под таблицей: `будет сохранено: <папка> / <имя>.xlsx`. После сохранения
   подсказка меняется на `Сохранено: <папка> / <имя>.xlsx`. Каждое сохранение
   даёт **новый файл** (`имя.xlsx`, `имя (2).xlsx`, `имя (3).xlsx`…) — старые
   не перезаписываются.

Без сверки колонок ровно 10, как в образце; при сверке добавляется «Новинка».
Если для разбора расхождений нужны колонки «файл» и «строка» (откуда взята
позиция), запустите консольную версию с ключом `--source-columns`.

Реквизиты читаются не только из ячеек: если поставщик, УНП, номер и дата
нарисованы **текстовым полем поверх листа** (так делают выгрузки из 1С),
программа их тоже находит — например, у счёта `Счет СЧЦБ-17059130.xlsx`
поставщик `ООО "ТД Комплект"`, УНП 192775574, счёт № СЧЦБ-17059130 от 10.11.2026.

Числа в таблице показываются так же, как в Excel: **деньги** — с копейками
(`2,50`), а **количество и ставка НДС** — без лишних нулей и без запятой
(`12`, `20`; дробное количество — `0,5`).

### Настройка таблицы

Поля слева до «% совпадения» включительно закреплены; остальные находятся
справа. Горизонтальной полосы нет; если правая часть не помещается, используйте
Shift + колесо мыши над ней. После ручного изменения ширин заголовков нажмите
«Конфигурация» → «Закрепить поля». В том же окне есть сброс ширин.

## 4. Сверка с ведомостью остатков ТМЦ

Ведомость — выгрузка из учётной системы: «Склад», «Группа номенклатуры»,
«Артикул», «Номенклатура», «Ед.», «Конечный остаток», «Цена последнего
поставщика», «Последний поставщик». Сверка нужна, чтобы в итоговой таблице
номенклатура называлась **так же, как в учёте**, а не так, как её написал
поставщик в счёте.

1. Нажать **«Загрузить ведомость…»** и выбрать файл ведомости. В строке
   «Ведомость:» появится имя файла, число позиций и поставщиков. Большая
   ведомость (30 тысяч строк) читается несколько секунд — окно при этом
   остаётся живым.
2. Выбрать счёт/накладную и нажать кнопку конвертации с нужным способом
   подбора: **по штрихкоду**, **по артикулу** или **по наименованию**.
3. Программа ищет номенклатуру только среди строк выбранного склада и
   выбранных поставщиков. При смене склада список поставщиков обновляется.
   Колонка «Склад» обязательна для подбора по складу: если её нет или на
   складе нет поставщиков, выбрать их невозможно.
4. Подбор по названию нечёткий: «Грунтовка акриловая Тайфун Мастер № 100
   белая, 1кг» находит «Грунтовка акрил.Тайфун Мастер №100 бел.1кг.»;
   учитываются сокращения, латиница/кириллица вперемешку, числа (35 л не
   путается с 40 л) и главное слово (бачок не превращается в сиденье).
5. В таблице результата две колонки наименования — **«Из документа»** и
   **«Из ведомости»** — узкая колонка **«▼»** и колонка **«% совпадения»**.
   Сразу видно, что написал поставщик, что подобрала программа и насколько
   уверенно.
6. **Номенклатуру выбирают «птичкой вниз» (▼)** — она стоит справа от
   колонки «Из ведомости». Щелчок открывает список:
   * похожие позиции ведомости с процентом совпадения и артикулом — выбор
     берёт название из ведомости;
   * **«— не выбирать (новый товар) —»** — название документа остаётся,
     а в файле эта позиция попадает в «Новинки»;
   * **«Своё название…»** — вписать любой текст.
   Двойной щелчок по ячейке «Из ведомости» делает то же самое.
   Список закрывается сам, если таблицу прокрутили (колесом или полосой) —
   он не «висит» на месте. Строка с ручной правкой подсвечивается, в
   «% совпадения» появляется «вручную» или «не выбирать». Правка сразу
   попадает в сохраняемый файл.
7. В итоговой таблице (файле) **10 колонок образца плюс колонка «Новинка»**
   сразу после «сумма с НДС» (только при сверке с ведомостью): у позиций,
   где номенклатуру не выбрали или не нашли, написано слово **«Новинка»**.
   В «Наименование товара» идёт выбранное название; артикул, штрихкод и
   единица подставляются из ведомости, только если в документе их не было.

Подсказка под таблицей показывает итог, например:
`сверено с ведомостью: 9 из 11 (по наименованию 9), проверить 7, не подобрано 2`.

## 5. Что получается на выходе

Книга Excel из трёх листов.

### Лист «Данные»

Ровно те 10 колонок, что в образце. Сверху — шапка (закреплена), включён автофильтр,
внизу — строка **ИТОГО** с формулами (`=СУММ(...)`), поэтому при правках суммы
пересчитываются.

**Жёлтая заливка** ячейки означает: в документе этого числа не было, и программа
его рассчитала (например, в накладной есть количество и цена, но нет колонки «сумма»).
Жёлтые ячейки стоит просматривать внимательнее — это расчёт, а не данные поставщика.

### Лист «Проверки»

Каждое замечание с указанием файла, листа, строки и наименования:

* **ОШИБКА** — числа в документе не сходятся (например, «сумма 25,00 ≠ количество × цена
  2 × 10,00 = 20,00»). Такой документ стоит уточнить у поставщика;
* **ВНИМАНИЕ** — итог документа не совпал с суммой строк; нестандартная ставка НДС;
* **РАСЧЁТ** — значение рассчитано программой.

Если расхождений нет, на листе будет одна строка «Расхождений не найдено — все суммы сошлись».

### Поставщик и дата документа

Программа сама читает из файла поставщика его название (и УНП), тип и номер
документа и дату. **Поставщиком никогда не считается наша организация**
(«Мирстроймаркет», «Мирсититорг») — даже если её название напечатано в самом
верху счёта как получатель или плательщик. Свой список наших организаций можно
задать переменной окружения `KONVEKTOR_OUR_COMPANIES` (названия через запятую).

Поставщик и дата:

* на листе «Сводка» — столбцы «Поставщик», «УНП поставщика», «Документ»,
  «Дата документа» (по строке на каждый исходный файл);
* в журнале работы и в итоговом сообщении после сохранения — по каждому файлу.

Если в файле этих сведений нет, в «Сводке» будет «— не найден» или «—»,
а данные при этом переносятся как обычно.

### Оценка разбора: «Качество разбора», «Доверие», «Проверить»

Программа не только переносит данные, но и оценивает, насколько уверенно она
поняла файл: сколько смысловых колонок найдено из десяти, сходятся ли суммы
(кол-во × цена, сумма + НДС), заполнены ли ключевые поля. Итог — столбцы
«Качество разбора» (высокое/среднее/низкое), «Доверие» (0…1) и «Проверить»
(жёлтая заливка у файлов, где стоит посмотреть глазами). Файлы с пометкой
«требует проверки» также перечисляются в итоговом сообщении.

Хотите увидеть, **как** разобран файл (какая колонка за что принята и почему) —
запустите `Konvektor-cli.exe --explain "имя файла.XLS"`.

### Лист «Сводка»

По каждому файлу: сколько позиций распознано, суммы, количество замечаний,
сколько значений рассчитано, определённый режим НДС и формат файла.
Внизу — замечания по чтению (например, «шапка таблицы не найдена»).

## 6. Как программа понимает разные документы

Названия колонок у поставщиков отличаются, поэтому программа ищет их **по смыслу**:

| Что нужно | Как может называться в документе |
|---|---|
| Штрихкод | Штрихкод, Штрих-код, EAN, EAN-PEACE |
| Артикул | Артикул, Арт., Код, Код товара |
| Наименование | Наименование товара, Номенклатура, Товар, Товары (работы, услуги), Наименование материала |
| Ед. изм. | Ед. изм., Единица измерения, Ед. |
| Количество | Количество, Кол-во, К-во, Заказанное количество |
| Цена | Цена, Цена за единицу, Цена шт. б/НДС |
| Сумма | Сумма, Стоимость, Сумма без НДС |
| Ставка НДС | Ставка НДС, Ставка НДС % |
| Сумма НДС | Сумма НДС, НДС |
| Сумма с НДС | Сумма с НДС, Стоимость с НДС, Всего с НДС, Всего |

Не нужные колонки («Код ТНВЭД», «Вес», «Страна», «Количество грузовых мест»,
«Масса груза», «Примечание»…) игнорируются.

Если **штрихкода нет отдельной колонкой**, он ищется в наименовании — программа
распознаёт 8-, 12-, 13- и 14-значные коды и проверяет контрольную цифру EAN,
поэтому номера ТУ/телефоны/декларации за штрихкод не принимаются.

Если **артикула нет отдельной колонкой**, он ищется в наименовании: `арт. 08135`,
`артикул: N451`, а также ведущий код вида `8160612 Вода питьевая…`.

Таблицы, которые повторяются на нескольких страницах (ТТН-1, приложения к ТТН),
читаются целиком — все страницы попадают в общий список.

## 7. Если что-то пошло не так

| Сообщение / симптом | Что делать |
|---|---|
| «Позиции не найдены» | В файле нет таблицы с колонками «наименование», «количество», «цена». Проверьте лист «Сводка» → «Замечания по чтению файлов». Пришлите файл разработчику. |
| Много строк «ОШИБКА» на листе «Проверки» | Программа выбрала не ту колонку (например, «Цена с НДС» вместо «Цена без НДС»). Пришлите файл разработчику — добавляется правило. |
| Пустые «Штрихкод»/«Артикул» | В документе их действительно нет. Можно включить колонки «файл»/«строка» и добрать вручную. |
| «Поставщика … в ведомости нет — подбор только вручную» | В ведомости нет позиций этого поставщика (другое написание или его там нет). Нажмите «▼» справа от «Из ведомости» и выберите позицию (или «Своё название…»), либо выберите пункт «— не выбирать (новый товар) —»: тогда останется название документа, а в файле будет «Новинка». |
| «в файле не найдена колонка «Номенклатура» | Это не ведомость остатков (или в ней другая шапка). Нужна выгрузка, где есть заголовки «Артикул», «Номенклатура», «Ед.», «Последний поставщик». |
| Числа выглядят как текст | Выделите колонку → «Данные» → «Текст по столбцам» → «Готово». Либо сообщите: программа выгружает числа числами. |
| «Не удалось записать файл…» | Папка, где лежит исходник, недоступна для записи (защищённая папка, сетевой диск только для чтения, файл открыт). Программа сама сохранит результат в «Документы» и скажет, куда именно. |
| Файл не читается («XLS не смог конвертировать») | Программа сообщит об ошибке и продолжит с остальными файлами. Запустите `Konvektor-cli.exe --diagnose "имя файла.XLS"` — он покажет формат, листы, найденные реквизиты, количество позиций и полный текст ошибки. Этот вывод (и сам файл) пришлите разработчику. Частые причины: файл открыт в Excel (закройте), файл повреждён или это не настоящий Excel (HTML/CSV с расширением `.xls`). |

Ограничения: пароль на файл Excel, сканы (PDF/картинки) и файлы `.ods` не поддерживаются.
Книги с несколькими листами обрабатываются: читаются все листы, в которых есть таблица.

## 8. Пакетная обработка (консоль)

```
Konvektor-cli.exe счет.xls ТТН.xlsx -o Загрузка.xlsx
Konvektor-cli.exe C:\Счета\октябрь -o C:\Итог.xlsx --mode files --json
Konvektor-cli.exe --help
```

Сверка с ведомостью в консоли:

```
Konvektor-cli.exe счет.xls --vedomost "Ведомость 08.11.2026.xlsx" --match name --sklad Мир -o C:\Отчёты
Konvektor-cli.exe счет.xls --vedomost "Ведомость.xlsx" --match article   (или barcode)
```

Полезные ключи: `--vedomost` (файл ведомости), `--match` (barcode | article | name),
`--sklad` (Мир | Кореличи — раскладка `<склад>/<поставщик>/<дата>.xlsx`),
`--supplier` (поставщик вручную),
`-m/--mode` (combined | sheets | files), `-r` (включая вложенные папки),
`-o` (куда сохранить), `--json` (машиночитаемый итог), `--strict` (код возврата 3,
если есть расхождения в суммах), `--selftest` (самопроверка), `--diagnose "файл.XLS"` (подробно объяснить, почему
файл не читается: формат, листы, реквизиты, позиции, текст ошибки).

Кроме того, `Konvektor-cli.exe` можно запускать по расписанию (Планировщик заданий
Windows) для автоматической обработки папки с новыми счетами.
